# Publication Scope

**Current status: public since 18 November 2026.** Visibility was changed at the owner's
explicit instruction. This does not certify separate coauthor approval or confer a new
code/data licence. Dated October records retain the status that applied at creation.

## Included and Excluded

| Scope | Material |
| --- | --- |
| Public computational package | Statistical code, environment, tests, instructions, prompt templates/settings, pseudonymised numeric/category inputs, redacted factor annotations and saved matching decisions, quotation offsets/hashes, 210 study-to-JCQHC links, aggregate results and provenance |
| Public reading copies | Dated Supplementary Methods, Supplementary Results and GRRAS checklist; see the [current index](../manuscript-supplements/20261118/README.md) |
| Not included | Source narratives/metadata exports, factor prose and quotations, complete individual annotation exports, original model responses and clinical few-shot examples |
| Not distributed through this package | Reviewer identities/contacts and identity mappings, internal comments/activity logs, credentials, third-party paper PDFs and original working-repository history |

Persistent A-F reviewer codes and case links allow records to be joined. Absence of a
name mapping does not make linked assessments anonymous aggregate data.
Current independent extraction uses 248 factors; the 244-factor reassessment baseline
is kept separately. Historical October data must not replace current calculation inputs.

## Reproduction Boundary

The package reproduces statistics conditional on saved classifications, semantic
correspondences and traceability flags. It does not independently validate factor
meaning, establish causation or rerun the original AI pipeline. Current FTA statistics
are recomputed from code-only saved trees and category sets; original clinical
few-shot messages are not included. See [reproduction commands](reproduction.md)
and [interpretation limits](limitations.md).

## Sources, Citation and Licensing

Original public records can be obtained from JCQHC under applicable source terms;
see [source acquisition](data_availability.md#obtaining-the-original-public-sources).
No blanket prohibition on lawful research reuse is asserted, and no additional licence
to redistribute JCQHC text is granted. Withheld material is not automatically available
on request; any additional release requires a separate decision.

No open-source/data licence or archival DOI has been assigned. Cite the repository
and exact calculation commit. Journal submission supplements remain separate files
in the journal's required format. Reading copies do not update automatically when
the collaborative manuscript changes.
