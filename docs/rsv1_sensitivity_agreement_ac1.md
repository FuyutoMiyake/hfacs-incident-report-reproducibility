# Extended RSv1 sensitivity results: agreement and AC1

**Historical sensitivity table**, retained unchanged from the original working supplement.
Its 2,000-bootstrap intervals are not the current manuscript calculation.
Use the [current supplements](../manuscript-supplements/20261118/README.md) and
[reproduction guide](reproduction.md) for the current revision.

RS = reference standard; AC1 = Gwet's agreement coefficient 1; CI = confidence interval; HFACS = Human Factors Analysis and Classification System.

These values are exported unchanged from the original working Methods supplement. Non-primary agreement and AC1 estimates are not duplicates of the kappa-only Supplementary Results Table S3. They are preserved here rather than discarded.

All conditions retain records judged analysable by both reviewers and nodes retained by both. Primary: records 11-50, leaf nodes, after L1 reassessment, 22 categories. Each sensitivity row changes the indicated dimension only. The merged non-HFACS condition uses 20 categories. Agreement is a percentage; CIs use 2,000 record-cluster bootstrap resamples. AB, CD and EF assessed different records.
