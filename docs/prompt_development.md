# Exploratory FTA prompt development

Historical repository-preparation description; the repository is now public.
These exploratory comparisons are not the final validation results.
See the [current reproduction guide](reproduction.md).

FTA = fault tree analysis; HFACS = Human Factors Analysis and Classification System; RS = reference standard.

Three two-stage variants were compared on the same 10 previously selected development records. The comparison was exploratory and non-random, without an independent reference standard.

| Variant | Improvement measures | Explicit prohibition on unsupported inference | Decision |
| --- | --- | --- | --- |
| v5b | Included | No | Not adopted |
| v6 | Excluded | Yes | Not adopted for original RSv1 generation |
| v6b | Included | Yes | Adopted for original RSv1 generation |

v6b retained all three narrative fields while prohibiting unsupported inference. This was a development choice, not proof of superior accuracy. The 10 records were part of the seed-671 development sample, excluded from the 150-record RSv1 cohort. The later FTA added-value analysis regenerated trees without improvement text; it was a separate task.
