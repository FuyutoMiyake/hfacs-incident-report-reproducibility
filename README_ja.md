## 再計算

[英語README](README.md#reproduce-the-statistics)のコマンドで環境作成・整合性確認・再計算を行えます。
検証環境はPython 3.14です。APIキー・新たなモデル呼出しは不要です。
bootstrapは10,000回で、検証結果は `outputs/current/recomputation.json` に出力します。

## 公開範囲と利用上の注意

計210例のJCQHC事例ID対応表、引用位置・hash、継続して使われる評価者コードを含みます。
評価者名との対応表は含みませんが、仮名化された個別判定は匿名の集計データとは異なります。

原文・要因文・引用文、個別回答全文、AI応答全文、臨床few-shot、評価者名・連絡先、
内部コメント、認証情報、元研究リポジトリの内部履歴は収録していません。
元の公開報告は、適用される利用条件に従って別途取得する必要があります。

コード・データのオープンライセンスとDOIは未設定です。公開したことは、第三者資料の
再配布許諾や追加資料の提供を約束することではありません。引用時はURLと固定commitを明記してください。
