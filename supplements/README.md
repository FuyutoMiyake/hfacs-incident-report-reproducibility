These are readable Markdown copies of the active text in the latest collaborative
documents at capture. The originals were read only and were not edited. They remain
the collaborative manuscript sources; subsequent edits do not automatically update
this repository. Manuscript section references and availability statements in these
snapshots reflect the draft at capture and must be checked before submission.

identified as `gpt-6.1-sol`; the standalone matching prompt and earlier AB/CD candidate
creation remain unresolved. See [the recovered provenance](../docs/semantic_matching_provenance.md).
The earlier Methods/checklist wording about an unidentified model is retained as part
of the dated collaborative-document snapshot, not the latest provenance conclusion.
Updated [source acquisition and access conditions](../docs/data_availability.md) do
not alter the source Docs, supplement tables or repository permissions.

The export omits struck review text/tables, private collaboration links and a separate
internal author-confirmation section. References and the checklist's pending items
are retained. No clinical narratives, extracted factor prose, quotations, reviewer
identities or coauthor comment threads are added. Relative links connect the copies.
The [supplement manifest](../provenance/supplement_manifest.json) records hashes and
checks; native document IDs and review records are retained only in the research
workspace.

Journal submission copies can be prepared from the final reviewed supplements in
the journal's required format. Hosting these readable copies does not remove the
need to provide any supplement requested by the journal.

For numerical recomputation use the [reproduction guide](../docs/reproduction.md).
The numeric/category data in this repository are public-release candidates accepted
for author review, not a public release or a claim of independent source verification.
